This is a metapuzzle. The input for this puzzle comes from four other puzzles: Argument Checker, Big Ideas, Four Crosses and Mad Scientist Store. When you enter a correct solution to each of those puzzles, you will be given a set of four fragments each with four letters. When you’ve solved all four puzzles, you’ll have a total of 16 fragments. Reformat each fragment by adding a line break between the 2nd and 3rd letter to make these 16 2x2 tiles:

Now rearrange twelve of the tiles to make three word squares, where all four rows in each square are words and all four columns (read top to bottom) are also 4-letter words. Cutting them out might help but probably isn’t necessary or desirable.

Take the four remaining tiles and arrange them left to right as two eight letter rows.

Read the three-word phrase which is the clue for the three-word bad idea final answer, the second word of which is ‘and’.
