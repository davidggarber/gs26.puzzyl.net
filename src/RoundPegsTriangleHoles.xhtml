Below is a collection of 36 pegs, arranged into six regions spiraling out from the center.

These circles need to be filled with the digits 1-6, subject to a few rules:

  • Each region is color coded, and also separated by dashed lines.
    Each region contains pegs for the digits 1-6, used exactly once each.
  • Some digits are already given, shown in a larger font.
  • No adjacent pegs contain the same digit.
  • Numbers in parentheses (smaller font) are the sums of the digits from all adjacent pegs.
